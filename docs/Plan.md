## 1. Scope
Deliverables 1–6 of the assessment (calibration, dataset, segmentation model, image-to-mm command, calliper accuracy, undistortion proof).
Deliverables 7–10 are not implemented. They are listed as not done in the Definition of Done.

## 2. Object and reference
- **Object:** one white A4-sized paper sheet, lying flat on a dark cloth.
  - Size: about 290 × 205 mm (ruler measurement). Exact calliper size is pending and will replace this.
- **Reference:** a printed ArUco marker (4×4), measured with a calliper, lying in the same plane as the paper.
- **Calibration board:** a checkerboard generated by this project, 9 × 7 inner corners, 20 mm squares, printed at 100% (no fit-to-page). The printed square size will be measured with a calliper and used in code, not the file value.

## 3. Hardware and software
- Intel Core i7-8650U, 16 GB RAM, Intel UHD 620 (no CUDA), Windows 11 Pro.
- Camera: phone (model to be recorded). Focus, zoom and resolution locked for every image.
- Python, OpenCV, PyTorch (CPU), torchvision, pycocotools. Exact versions pinned in requirements.txt.

## 4. Approach
1. **Calibration:** 20+ checkerboard photos → OpenCV `calibrateCamera` → save camera matrix and distortion coefficients → report reprojection error.
2. **Dataset:** 100 photos of the paper (must be ≥ 70). Undistort every photo. Label masks in a labelling tool (CVAT or Label Studio). Fixed split 70/20/10 committed as `dataset/split_v1.csv` (seed 42) before training.
3. **Model:** torchvision Mask R-CNN (ResNet-50 FPN), COCO-pretrained, fine-tuned on our train split only. Input resized to 512 px for CPU speed. Validation split is used for checkpoint choice. Test split is evaluated once.
4. **Inference command:** undistort → segment → detect ArUco → convert pixels to mm using the reference scale → output width, height, confidence, mask overlay. Handles "object not found" and "reference not found".
5. **Accuracy:** measure 10 instances with a calliper and with the system. Compare raw and undistorted images.

## 6. Known risks
- Labelling time is the largest risk. If it runs over, the number of photos stays at 70 (minimum), and the test split stays fixed.
- CPU training time is not measured yet. If one epoch is too slow, the epoch count is reduced and this is written in the Objectives document.
- Paper is not perfectly flat (a crease is visible). Flattening and weights on the corners are required before shooting.

## 7. Decision record
- **Chosen:** flat paper sheet as the object, ArUco marker as the reference, both lying on the same surface.
- **Rejected:** Ronin Stellar box as the object. Its front face is 25 mm above the table. A reference on the table would give a scale error of about 9% at 30 cm camera distance. The box would need a raised support and a flat setup to fix this.
- **Cost of rejecting the box:** the earlier box measurements (90 × 170 mm front face, 25 mm depth) are not used. The paper is flatter and has a simpler scale, but it is a less interesting object.
- **Model rejected:** YOLO and Roboflow models are not allowed by the assessment. Mask R-CNN was chosen because it is permitted, has instance masks for the mAP metrics, and can be fine-tuned on CPU at a small input size.
